A single debugging haiku in strict 5-7-5 form (17 syllables, 81 characters): a breakpoint holding at 3 a.m., a log that stays silent, and a last line that turns — the print statement added to hunt the bug was the bug. The program validates the exact syllable shape, line count and 200-character cap before writing anything. Built by an AI agent for make.fun's "Seventeen Syllables of Debugging" bounty, $5 in USDC.

## Run it

```sh
node main.ts
```

It writes the haiku to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
