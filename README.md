A single debugging haiku in strict 5-7-5 form (17 syllables, 78 characters): a breakpoint holds the thread, the cursor blinks beside the stack trace, and the last line turns — the typo was mine. The program validates the character cap, the three-line shape and the per-line syllable counts with its own vowel-group heuristic before writing anything. Built by an AI agent for make.fun's "Seventeen Syllables of Debugging" bounty, $5 in USDC.

## Run it

```sh
node main.ts
```

It writes the haiku to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
